# maccms-merge-vod — 苹果cmsV10 视频去重合并插件

一个开源的 **maccms10（苹果CMS V10）** 应用插件：把"不同播放器下的相同资源"自动合并，并删除重复记录。

- 同一影视因多个采集源（如天堂、西瓜、非凡等）各生成一条记录时，自动合并为一组；
- 保留播放源最多的一条记录，把所有播放器（`vod_play_from` / `server` / `note` / `url`）汇聚到保留记录上；
- 删除其余重复记录；
- 支持后台管理、预览、定时任务自动执行。

> 目录结构遵循 maccms10 标准插件规范：插件放入 `addons/` 后，后台「应用 → 应用市场 → 本地应用」即可看到本插件卡片，可配置、可启用/禁用。

## 安装

1. 将本仓库 `addons/mergevod/` 整个目录上传到苹果cms站点根目录下的 `addons/` 中（最终路径：`站点根/addons/mergevod/`）并解压。
2. **设置权限（务必执行）**：Windows 打包的 zip 不含 Unix 权限位，解压后文件可能是 `644/root`，PHP（www 用户）将无法写入配置。请在宝塔「终端」或 SSH 执行：

   ```bash
   cd /www/wwwroot/你的站点根/addons/mergevod
   chown -R www:www .
   chmod -R 755 .
   ```

   目录/文件归 www 所有且 755，后台「配置」才能正常保存。（若你在宝塔文件管理器操作，可对 `addons/mergevod` 右键 → 权限 → 所有者选 www、权限 755、勾选「应用到子目录」。）
3. 登录苹果cms后台，进入「应用 → 应用市场」，在「本地应用」中找到 **视频去重合并**，点击 **启用**。
4. 点击 **配置**，重新填写（**注意**：重新上传解压会把 `config.php` 覆盖回默认值，鉴权密钥会被重置，必须重新设置）：
   - **鉴权密钥**：改为随机长字符串（管理页与定时任务都用它鉴权）；
   - **按分类匹配**：推荐「片名 + 分类都相同才算重复」；
   - **合并前备份**：首次使用建议开启；规则确认无误后可关闭以省磁盘。

## 使用

### 一、后台预览 / 执行

启用并配好密钥后，访问管理页：

```
http://你的域名/插件管理地址?key=你的密钥
```

管理页会展示当前重复分组（视频总数、重复组数、保留记录、将删除记录），并有「执行合并」按钮。

> 在插件管理页里已自动显示正确的管理地址与定时任务地址，直接复制即可。

### 二、定时任务自动执行（推荐）

用宝塔（或系统 crontab）每小时调用一次，新采集进来的重复记录会被自动合并并删除。

> 定时任务请使用插件自带的**独立物理入口** `run.php`（`addons/mergevod/run.php`），它是 nginx 直接执行的 PHP 文件，不依赖 thinkphp 的 `/index.php/addons/` 伪静态路由（该路由可能被 nginx `try_files` 拦截而返回 404）。

```bash
curl -s "http://你的域名/addons/mergevod/run.php?key=你的密钥"
```

宝塔「计划任务」示例（每小时第 40 分钟，避开采集任务）：

```bash
curl -s "http://你的域名/addons/mergevod/run.php?key=你的密钥" | grep -oE "执行完成[^\\n]*|没有发现可合并的重复记录"
```

`run.php` 输出纯文本：
- 无重复：`没有发现可合并的重复记录`
- 有执行：`执行完成：合并 N 组，新增合并播放源 N 个，删除 N 条重复记录`

## 匹配规则

- 规范化片名：去除所有空白（含全角/零宽/NBSP）、并去掉末尾年份（如 `美人余2026` → `美人余`）；
- 默认「片名 + 分类」都相同才视为重复（可在配置中改为只看片名）；
- 每组保留**播放源最多**的记录，播放源个数相同时保留 **vod_id 较小**者；
- 合并后，保留记录拥有全部播放器；重复记录被删除。

## 还原

若开启了「合并前备份」，执行合并时会在 `站点根/runtime/` 生成 `merge_backup_时间戳.sql`。
用 phpMyAdmin 导入该文件即可恢复合并前状态。

## 目录结构

```
addons/mergevod/
├── Mergevod.php          # 插件核心（安装/卸载）
├── info.ini              # 插件信息（应用市场卡片）
├── config.php            # 后台「配置」表单
├── run.php               # 独立执行入口（定时任务 curl 调用，物理文件，nginx 直接执行）
├── controller/
│   └── Index.php         # 管理页 / 执行合并 / 定时任务接口
├── view/
│   └── Index/index.html  # 管理页视图
└── LICENSE               # MIT
```
